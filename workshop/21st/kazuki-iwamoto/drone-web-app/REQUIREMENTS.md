# 要件定義

## 概要

Drone Web App は、CLI ベースのドローン制御をブラウザ操作に置き換えるためのローカル Web アプリケーションです。FastAPI バックエンドが MAVLink 機体と通信し、WebSocket 経由でフロントエンドへ状態配信とコマンド受付を行います。

## 目的

- ドローンの基本操作をブラウザから実行できるようにする
- 機体状態をリアルタイムに確認できるようにする
- 地図上で現在位置と飛行軌跡を視覚的に把握できるようにする
- ビルドツール不要の最小構成で学習・検証しやすくする

## ターゲットユーザー

- MAVLink/SITL を使ってドローン制御を学ぶ開発者
- CLI 操作から Web UI 操作へ移行したいユーザー
- ローカル環境で簡易的なドローン制御画面を試したいユーザー

## 機能要件

- WebSocket 接続直後に現在状態を送信する
- ユーザー操作により MAVLink 接続を開始する
- アーム、ディスアーム、離陸、着陸、GoTo、モード変更コマンドを送信できる
- 離陸と GoTo は実行前に GUIDED モードへの切替を試みる
- MAVLink HEARTBEAT からアーム状態とフライトモードを更新する
- MAVLink GLOBAL_POSITION_INT から緯度、経度、高度、ヘディングを更新する
- GCS や無効な autopilot の HEARTBEAT は状態更新対象から除外する
- 状態更新は `{"type":"state","state":{...}}` として送る
- コマンド結果は `{"type":"status","message":"..."}` として送る
- Leaflet 地図で機体マーカー、ポップアップ、飛行軌跡を表示する
- WebSocket 再接続時に飛行軌跡をクリアする

## 非機能要件

- 接続待ちと MAVLink 受信で FastAPI のイベントループをブロックしない
- 未接続時に制御コマンドを送信してもサーバーが落ちない
- MAVLink 受信例外はログに残し、受信ループを継続する
- フロントエンドはビルド不要で配信できる
- スマートフォン幅でも主要操作と地図表示が破綻しない
